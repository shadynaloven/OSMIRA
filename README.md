# OSMIRA PWA

OSMIRA adalah prototype Progressive Web App (PWA) untuk edukasi kesehatan ginjal dan skrining edukatif faktor risiko AKI/CKD.

## Cara menjalankan
Buka `index.html` di browser untuk preview dasar. Fitur install dan service worker memerlukan hosting HTTPS atau localhost.

## Deploy ke GitHub Pages
1. Buat repository GitHub bernama `osmira`.
2. Upload seluruh isi folder ini (bukan folder luarnya) ke root repository.
3. Pastikan file `index.html` berada di root.
4. Buka Settings → Pages.
5. Pada Build and deployment pilih Deploy from a branch.
6. Pilih branch `main`, folder `/ (root)`, lalu Save.
7. Setelah deployment selesai, buka URL Pages yang diberikan GitHub.

## Pasang di ponsel
- Android/Chrome: buka URL GitHub Pages → menu ⋮ → Install app atau Add to Home screen.
- iPhone/Safari: buka URL → tombol Share → Add to Home Screen.

## Batasan prototype
- Skrining bersifat edukatif, bukan instrumen klinis tervalidasi dan bukan diagnosis.
- Tidak ada akun, database, penyimpanan data pasien, atau sinkronisasi cloud.
- Jangan memasukkan data pribadi atau informasi medis yang sensitif.
- Materi perlu ditinjau dosen/pembimbing dan disesuaikan dengan pedoman klinis sebelum penggunaan publik.
